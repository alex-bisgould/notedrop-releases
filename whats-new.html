1.16.0 What got done 2026-09-24
New
  • This week, in the sidebar: the last seven days in one place. What was filed and where, what is still waiting in the Inbox and Review, which tasks were closed and how many are still open, and what sessions logged. A question a session asked is spelled out, since it is the one entry waiting on you.
  • Copy as text puts the same digest on the clipboard, ready to paste into a journal or a message. No model is involved and nothing leaves your Mac.
  • Activity, in the sidebar: every entry Claude sessions have written into your notes' work logs, newest first and grouped by day. What each one did, which tasks it closed, and the commit if it gave one. Narrow it to one session or a time range; NoteDrop's own entries stay out unless you ask for them.
Improved
  • Re-checking a category's filings can act on the answers. Move all moves every proposal you have not decided on, and Keep it here turns one down. Each move is still recorded as a correction, so the classifier learns from a bulk move exactly as from a single one.
  • The re-check summary counts the notes it could not check, skipped as quarantined, or was told belong in a category that does not exist, and names those categories. Before, they were left out of every number.
  • Closing a task records when, so a tick you make in NoteDrop counts toward the week it happened in.
Fixed
  • Ticking a task in Open Tasks failed and unticked itself every time, and had since the view first shipped. It works now, and a tick names the task by its id, so if another session rewrote the note in the meantime the right task still closes.
1.15.0 Knowing what this is 2026-09-22
New
  • About NoteDrop is a page in the app rather than the stock macOS box. What this is and why, plus your own store: how many notes, categories, open tasks and quarantined notes you have, and where they live.
  • Links out to the download page, the roadmap and the privacy policy, and a button that copies a short message and the link, ready to paste to somebody.
  • The same two as small buttons beside What's New in the sidebar.
  • A page on the website saying what NoteDrop is, for anyone you send the link to.
Improved
  • Updates are checked again when you come back to the window, so a copy left open all day notices within seconds rather than up to six hours later. It has always checked on launch and every six hours — what it could not do was notice you had returned.
  • An update that arrives while NoteDrop is not in front now sends a notification. The banner only ever existed inside the window, so the only other signal was a Dock badge reading 1.
  • Settings says when it last checked, so “no update waiting” is a statement with something behind it.
Fixed
  • The NoteDrop menu kept offering to install an update after you had installed it, dismissed it, or a later check found nothing. It now stops saying so.
1.14.0 Shortcuts you choose 2026-09-22
New
  • A Shortcuts tab in Settings. Change one, hold the keys you want, and save. Ten commands that never had a key can be given one — Add a thought, Send to, Share, Check for updates, Expand and collapse every section, and the store commands.
  • A combination already used by NoteDrop or by macOS is refused and named, rather than being accepted and then quietly doing nothing. A duplicate accelerator does not warn: the other item simply wins.
  • The quick capture key is recorded the same way instead of being picked from a short list, and says so when another app already owns it.
Fixed
  • The keyboard shortcuts sheet was a second, hand-kept list that had drifted from the menu — it omitted four shortcuts and named the wrong key for Settings. The menu, the sheet and the Settings screen now all read from one table and cannot disagree.
1.13.0 A thought about a note 2026-09-22
New
  • Add a thought to any note. Write what has changed since — what you finished, what you realised, what turned out to be needed — and NoteDrop reads it and proposes which tasks to close, what to add, and whether the summary needs rewriting. On that note, not on the thought.
  • The thought stays its own note, exactly as you wrote it. The original is never rewritten either: tasks are closed, not deleted, and each one records which thought closed it.
  • Every line of the proposal has a checkbox and nothing is written until you apply it. If the thought turns out not to be about that note, it says so and proposes nothing rather than forcing a match.
  • The Prompts screen now lists every prompt the app uses. Four of them — including the ones that describe a category, draw a border between two, and write a note for sharing — have been editable on disk for releases while being invisible there.
Fixed
  • Re-classifying a note threw away every task you had ticked. Tasks now carry a stable id and are merged rather than replaced, so a tick survives — and a task can be closed by name rather than by whichever one happens to be third.
1.12.0 Write it here 2026-09-22
New
  • Write a note in NoteDrop. ⌘N starts one, or use Write a note in the Inbox — and it is saved to a file before you type a character, so there is no draft to lose.
  • A third view on every note, beside Formatted and Raw: Edit. Your markdown, saved as you type.
  • A formatting bar that writes markdown into the file rather than styling a preview — bold, italic, code, strikethrough, headings, lists, task items and links, with ⌘B, ⌘I, ⌘E and ⌘K. The note stays plain text that any editor or agent session can read.
  • Expand a note to fill the window with ⌘⇧E, and escape to come back.
  • Notes written here carry the NoteDrop mark, so where a note came from is always shown rather than implied by the absence of a badge. A file captured from a watched folder now says so too.
  • Send a note you wrote here to Sublime Text, TextEdit or Notes and bring it back with your edits — the round trip already knew how.
Improved
  • Raw means something honest for a note you are writing: while it has never been classified, it is your markdown and follows every edit. Once classified it freezes as what you wrote, exactly as an imported note behaves.
1.11.0 Capture without opening the app 2026-09-22
New
  • Watched folders: drop a text file into one and it is captured into the Inbox, whether or not NoteDrop is open. The file is left exactly where you put it, and only text is taken — a screenshot or an archive in the same folder is ignored.
  • A quick capture shortcut that works from anywhere. Press it over whatever you are doing, type or paste, ⌘↩ to save and close, ⌘⇧↩ to save and keep going, escape to abandon. Off until you choose a combination, because a global shortcut fires no matter which app is in front.
  • An optional menu bar icon carrying the Inbox count, with quick capture and a way back to the window.
  • The credential scanner runs on everything captured this way too. A file dropped into a watched folder while you are not looking is exactly when that gate matters most.
1.10.0 Share without an account 2026-09-22
New
  • Share a note as an email, a Slack message, a Markdown file or plain text. Each is written for where it is going rather than wrapped differently — the same note read out loud in those four places is four different pieces of writing, and one rendering in four envelopes reads wrong in all of them.
  • Say who is reading it and the writing changes to suit. Left blank, it is written for a colleague who has never seen the note.
  • Every draft is editable before it goes anywhere, and comes with a note of anything you should know first — a plan with no owner, a question the note leaves open, a name it could not identify.
  • Copy it, open it in Mail, or save it as a file. NoteDrop composes; you press send. Nothing leaves this machine on its own, which is why none of this needs an account.
  • Quarantined notes cannot be shared, by the same gate that keeps them away from an AI provider.
1.9.0 Send a note back 2026-09-22
New
  • Send a note to Sublime Text, TextEdit or Notes. A new document is written and opened — nothing you already have open is touched — and the NoteDrop copy stays where it is, with the work log recording where the text went.
  • The copy that goes out carries the note's id, so bringing it back updates that note instead of creating a second one. The id line is stripped on the way in, and the work log records the round trip.
  • A NoteDrop Exports source in the import list, because a note you sent to TextEdit and saved is an ordinary file — neither TextEdit's nor Sublime's importer can see it, since both read only unsaved text. Optionally delete the file once its text is home.
  • Quarantined notes cannot be sent anywhere. The gate that keeps a credential away from an AI provider keeps it out of TextEdit too.
  • If a note comes back carrying a credential it was not carrying when it left, it is quarantined on arrival.
1.8.0 Everything still open 2026-09-22
New
  • Open tasks, on ⌘T: every unfinished task across every note in one list, grouped by the note it came from, oldest first. The tasks were always there, one note at a time, and there was no way to see them together.
  • A stale filter for tasks whose note has not been changed in a set number of days. That is the failure this app was built after — a TODO going quietly out of date in an unsaved tab, invisible whether it was done or not.
  • Tick a task off from the list without opening its note, and click any note's title to jump to it.
Fixed
  • The list header squeezed its own subtitle to one word per line whenever a view added more than a couple of controls beside the title.
1.7.0 A classifier that learns 2026-09-22
New
  • When you move a note out of where a model filed it, that is now recorded. The recent ones are shown to the classifier on every run, and they outrank the category descriptions — a description is what someone wrote down, a correction is what actually happened.
  • Re-check a category's filings: ask where each note in it would go today, and see only the ones the classifier would now place somewhere else. Nothing moves and nothing is rewritten until you say so — no title, summary or body is touched, because the question was only about where a note belongs.
Improved
  • The Categories editor puts the name and description first, with Save directly under them, and the colour and icon picker last where nothing needs saving.
1.6.0 Categories you can recognise 2026-09-22
New
  • Give a category a colour. Twelve to pick from, or Auto to keep the one derived from its folder name, which is what every category has had until now.
  • Or a stencil icon — thirty-odd of them, drawn for the things this app actually files: a wallet, a house, a bug, a briefcase, a plane. A stencil takes the category's colour.
  • Or the real thing: point at an image file, or at an app, and its own icon is used. A category that maps to a repo opens the picker in that folder, because the icon you want is usually sitting right there.
  • Icons live with your notes, in an _icons folder beside them, so they move when your notes move and reach another Mac if your notes are on iCloud or Dropbox. A picked app's icon is copied once rather than pointed at, so it survives that app being renamed, updated or deleted — and Refresh re-reads it when you want the newer one.
Improved
  • The category mark in the sidebar is bigger, and lines up with the Inbox and Review icons above it. A category you have not customised looks exactly as it did.
1.5.0 Categories you can tell apart 2026-09-22
New
  • A category can be called what it actually is. Rename projects/budget-tracking to WholeBudget and that is what you see — in the sidebar, on every note filed there, in the note header and in search results. The folder on disk does not move, and it is still there on hover and on the Categories screen.
  • Search matches the name and the aliases as well as the folder, so looking for WholeBudget finds the notes even though nothing on disk is called that. Rename it and search changes immediately, without a single note being touched.
  • Draw the border: one call that reads both competing categories and the notes filed in each, and writes both descriptions so each one says what belongs in the other. A border written from one side is not a border.
  • Distinct: say two categories only sound alike, and they stop being reported as competing. Recorded on both, so the question is not asked again from the other direction.
  • Merge: when two categories really are one thing. Every note moves and records the merge in its work log, the retired folder's name becomes an alias on the survivor so notes that still call it that arrive in the right place, and you choose which name survives.
1.4.0 Settings you can navigate 2026-09-22
New
  • Settings has tabs: Providers, Pipeline, Notes, Updates and Appearance. It had grown to show credentials and three model slots while everything else lived somewhere else entirely.
  • Notes gathers where your notes live, changing that location, revealing it in Finder, how the folders map to a note's state, and re-running first-time setup — previously a sidebar footer button and two menu items.
  • Updates shows the version you are running and adds a choice about whether updates download in the background. It was hardcoded off and unreachable. Installing still always waits for you.
  • Appearance is a home for the preferences that had no interface at all: whether a note opens Formatted or Raw, which of its sections start expanded, whether unused categories stay collapsed, and resetting the note list width.
Improved
  • A public roadmap at the download site, generated from the same file the repo keeps, showing what is shipped, planned and merely an idea with a value and effort score for each.
Fixed
  • Re-running first-time setup rebuilt the category list from scratch and could drop categories that were holding notes. Any category with notes in it now survives — with its description, aliases and mapped repo intact.
  • Filing a note into a folder the category list did not know about left that folder invisible to the classifier, so the next note that belonged there was filed somewhere else. Filing into a folder now registers it.
  • Archiving a category whose notes lived in a sub-folder moved those notes out of the app along with it. A category is now only archivable when nothing sits under it at any depth, and the Categories screen says how many notes a sub-folder holds instead of reporting the parent as empty.
1.3.0 Categories that know what they are 2026-09-22
New
  • Categories are editable. Press ⌘9 or Manage beside the Categories heading to change a category's name, what it is for, what a note might call it, and which repo it belongs to. Until now a category could be created and never changed again.
  • Draft a description from the notes already filed in a category. A folder's contents describe it better than its name does — fourteen notes about receipt scanning say more than the word "budget-tracking". Anything you have already written is refined rather than replaced, and you see both versions before either is saved.
  • NoteDrop now finds folders that hold notes but are not categories. These were invisible to the classifier, which is only ever shown registered categories — so notes kept piling up somewhere it could not choose to put the next one. Adopting a folder puts it back in the prompt, and nothing moves.
  • A rescan flags categories that look like they should not exist: empty, and named after a build directory, an application bundle or a repo that is gone. Archive one or keep it, and a keep is remembered.
  • Categories that compete for the same notes are reported as pairs, with the word they collide on. Two plausible destinations split related notes between them, which is worse than one vaguely-named folder.
Improved
  • Mirroring a folder into categories no longer creates one for src, data, scripts, build output or application bundles, and it says how many it held back rather than quietly returning a shorter list. Mirroring a folder that holds no code at all still creates a category for everything in it.
  • A category that has no description yet says so in the classify prompt, instead of appearing as a name followed by nothing.

Improved

1.0.0 First public release 2026-09-21
New
  • NoteDrop is a real release: signed by Apple, notarized, and updated in place from inside the app.
  • Choose where your notes live. The store can sit anywhere, and moving it carries every note, its original text and its file permissions with it.
  • First-run setup walks through the note location, a library of starter categories, and connecting an AI provider.
  • A category library you pick from — projects, work, money, home, life, thinking and reference — or mirror a folder so note folders match your repo names exactly.
  • What's New, below Settings, shows what shipped in each version.
  • Check for Updates in the NoteDrop menu, with a badge on the Dock icon when one is waiting.
Improved
  • The note store path in the sidebar footer is now a button that opens the relocation dialog.
0.5.0 It looks like an app 2026-09-21
New
  • An app icon, and the NoteDrop mark beside the app name in the sidebar.
  • A full macOS menu bar — File, Edit, Note, View, Window, Help — with shortcuts for classifying, splitting, closing, searching and jumping between views.

0.4.0 Your models, your keys, your notes split up 2026-09-21
New
  • Sign in with ChatGPT through the Codex CLI and use it as a provider in any slot — no API key needed.
  • Pick which key from ~/.secrets each provider uses, or paste one and store it encrypted with your Keychain; revealing it asks for Touch ID.
  • Any provider can fill any pipeline slot, with a typed model id, so a cheap classifier can feed a mid reviewer and a strong reconciler.
  • The reviewer can be gated on the primary's own confidence, so a note the classifier was sure about costs one call instead of two.
  • A note containing separator lines offers to split into one note per section, previewed before anything is written; the pieces point back to a single original.
Improved
  • Summary, tasks, verdicts, work log, related and provenance all collapse, and remember whether you left them open.
  • The Formatted/Raw choice sticks across notes, and R flips it.
Fixed
  • Opening the app asked for your Keychain password on every launch.
  • Long notes failed classification when a model's markdown ran past the first output estimate.
0.3.0 Find anything you wrote 2026-09-21
New
  • Search across every field of every note — title, summary, tasks, category, the formatted body, the raw original and the work log.
  • Each result names which fields matched and shows the text in context, so "found in the raw but not the summary" tells you the AI pass dropped something.
  • Quarantined notes stay findable but are never quoted: you get the field and the hit count, never the account number.
Fixed
  • Re-filing a note into the folder it already occupied renamed it.
0.2.0 Classification that shows its work 2026-09-21
New
  • Three-tier classification: a primary model files the note, a second provider reviews it, and a reconciler settles disagreements with a confidence score.
  • Notes whose reconciler falls below the threshold are held in the Inbox and shown with all three verdicts and their reasons.
  • The Review tray can create a category on the spot, typed or adopted from a repo directory name.
  • Editable prompt templates, shown alongside the variables they inject, resolved against a real note.
Improved
  • Only category and kind escalate to the reconciler. A title or task-wording difference does not change where a note is filed, and over 25 real notes, 8 of 10 reconciler calls had fired while both models already agreed on the category.
  • A note the reviewer agreed with now states that the reconciler was skipped, and every note shows how many API calls it took.
0.1.0 Get the text out of a volatile place 2026-09-21
New
  • Capture unsaved Sublime Text buffers into a structured note store, so loose text stops living in a session file that a crash would take with it.
  • A credential scanner runs before any network call and quarantines notes containing card numbers, account numbers or API keys to a local vault, with redacted filenames and no AI pass.
  • Notes are plain files: a markdown file with frontmatter beside the original text, byte for byte.
  • An AGENTS.md contract so other Claude sessions can find notes for a repo, log what they did, and close them.
