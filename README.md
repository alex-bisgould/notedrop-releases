# NoteDrop releases

Download page: **https://alex-bisgould.github.io/notedrop-releases/**

This repo holds the public releases and the download site for NoteDrop, a macOS
app for the text you never saved anywhere. Source lives in a private repo; this
one carries the builds.

- `index.html` — download page
- `whats-new.html` — every release, generated from the app's `releases.json`
- `privacy.html` — what leaves your machine, and what does not

Latest: **1.7.0** — A classifier that learns
