What it does

Drop it and forget itPaste or drag loose text in. NoteDrop reads it, titles it, summarises it and files it into a folder that makes sense.
Your notes stay filesEvery note is a markdown file with the original text beside it, byte for byte. Grep them, open them in any editor, point another tool at them.
Credentials never leaveA scanner runs before any network call. Anything that looks like a card or account number is quarantined locally and never sent to a model.
Two models, not oneA second provider checks the first one's filing. They disagree, a third settles it — and if it is not confident, the note waits for you.
Search what you actually wroteTitles, summaries, tasks, the formatted note and the raw original. Results say which field matched.
Built for agents tooAn AGENTS.md contract lets a coding session find the notes for its repo, log what it did, and close them out.

Installing

Open the downloaded NoteDrop-mac-arm64.dmg and drag NoteDrop to Applications. It is signed and notarized by Apple, so it opens without a warning.

On first launch NoteDrop asks where your notes should live and which categories you want. Nothing is uploaded, and it works without an AI provider — you just do the filing yourself until you add one.
