NoteDrop

For text that was never saved anywhere.

Download Roadmap

NoteDrop started with twenty-eight unsaved Sublime Text tabs — the kind of text that lives in a session file until something crashes. It captures that text, works out what each piece is, and files it where you and anything else on your machine can find it again.

Plain files, always

A markdown note with frontmatter beside the original text, byte for byte, in ordinary folders. No database and no lock-in: another app, another editor or another AI session can read your notes without asking NoteDrop for permission. Stop using it tomorrow and you keep everything.

Read before it is filed

A model classifies each note, a second one reviews it, and a third settles a disagreement about where it belongs. When they cannot agree confidently the note waits for you rather than being filed somewhere you will never look again.

Credentials never leave the machine

Everything is scanned before any network call. A card number, an account number or an API key sends the note to a local vault instead — no AI pass, no sharing, no export, and it is excluded from the contract other AI sessions read.

Bring in what you never saved

Sublime Text, TextEdit and Apple Notes, or point it at any other app and it looks for where that app keeps unsaved text. Watch a folder and anything dropped in is captured. Press a shortcut anywhere and type.

Write here too

Notes can be written in NoteDrop, in markdown, with a formatting bar that writes the markup into the file rather than styling a preview. Send one out to Sublime or Notes to edit and bring it back — it updates the note it came from rather than making a second one.

Come back to a note later

Add a thought to any note and NoteDrop reads it: which tasks it closes, what it adds, whether the summary has changed. It proposes; you decide. The original is never rewritten and the thought stays its own note.

NoteDrop is a personal project, built in the open with Claude. It is macOS only, it is free, and it has no account, no server and nothing to sign up to.
