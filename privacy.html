Privacy

Short, because there is not much to say.

Your notes are files on your Mac

NoteDrop writes every note as a plain markdown file in a folder you choose, with the original text beside it byte for byte. There is no NoteDrop account, no NoteDrop server, and nothing is uploaded anywhere by the app itself.

The only network calls are the ones you configure

Classification sends a note's text to the AI provider you set up — Anthropic, OpenAI, or your ChatGPT sign-in through the Codex CLI. That happens when you press Classify, or when you choose to classify a batch. Nothing is sent on a schedule, and nothing is sent if you never configure a provider.

The app also asks GitHub whether a newer release exists. That request contains no note content.

Credentials never leave the machine

Before any note can be sent to a provider, a scanner checks it for card numbers (Luhn-validated), account numbers near identifying keywords, API keys and similar. Anything that matches is quarantined to a local vault folder with restricted permissions, gets no AI pass at all, and is excluded from the contract other tools read. Search can find those notes but never quotes them.

API keys you paste into NoteDrop are encrypted with a key held in your macOS Keychain. Revealing one asks for Touch ID.

No analytics

No telemetry, no crash reporting, no usage tracking. The app has no way to tell anyone what you wrote or that you ran it.
